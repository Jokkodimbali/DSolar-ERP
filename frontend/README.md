# DSolar-ERP — Frontend

Répertoire réservé à la future application Angular de gestion interne.

Le projet Angular n'est pas encore initialisé. L'interface utilisera l'API du backend, des textes en français et la charte graphique D-Solar and Agri : framboise, bleu nuit, beige clair et blanc, sans dégradés, avec une mise en page responsive.

Les dépendances, scripts, configurations et tests frontend seront propres à ce dossier.
